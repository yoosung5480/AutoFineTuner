이 함수는 다음 단계를 수행한다:
(1) 데이터 로드 (테스트 세트 또는 입력 샘플)
(2) 모델 로딩 및 추론 수행
(3) 검증 및 평가지표 계산 (없을 경우 dummy metric 사용)
(4) 모델 저장 (optional)
(5) result.json 파일 작성
(6) stdout에 JSON 한 줄 출력
(7) log 파일 기록


# -----------------------------
# (1) 데이터 로드
# -----------------------------
- 추론 코드만 있는 경우 test_path 또는 입력 파일을 기반으로 데이터를 준비한다.
- 예시:
    X_test = np.load(args.test_path) 또는 pandas.read_csv(args.test_path)
- healthcheck 모드에서는 파일 존재 여부만 확인하고 "READY" 출력 후 종료한다.

# -----------------------------
# (2) 모델 로딩 및 추론 수행
# -----------------------------
- 원본 코드에서 모델을 로드하는 구문을 유지한다 (torch.load, keras.models.load_model 등).
- 예측 호출:
    preds = model.predict(X_test)
- 가능하다면 라벨 파일(y_test)이 존재하는 경우 정확도를 계산할 수 있도록 유지한다.
- 로그에 "Prediction completed" 메시지를 출력한다.

# (3) 검증 및 평가지표 계산  ← 강제 템플릿
